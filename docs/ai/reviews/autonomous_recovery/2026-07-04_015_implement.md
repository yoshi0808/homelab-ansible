# 自律復旧 Slack mute コマンド(自然言語)実装記録 — 2026-07-04

対象要求: 2026-07-02_001_requirement.md §要求6(Slack からの mute 操作)

## スコープ

Slack から自然言語で「sophos-fw を 60 分ミュートして」「monnie のミュートを解除して」
などを送れるようにする。

recovery-io.py は変更しない(全メッセージを Codex に渡す既存設計のまま)。
Codex(recovery-exec)が自然言語を解釈し `homelab-mute-exec` ラッパーを呼ぶ。

## アーキテクチャ

```
Slack mention (自然言語)
  → recovery-io.py (変更なし)
    → codex-exec-wrapper exec "<message>"
      → Codex (recovery-exec として実行)
        → homelab-mute-exec set/clear/status ...
          → sudo homelab-mute set/clear/status ...  (quory root)
```

## 変更ファイル

### `roles/recovery_exec/files/homelab-mute-exec` (新規)
- `exec sudo /usr/local/bin/homelab-mute "$@"` を実行するシェルラッパー
- execpolicy に登録するエントリポイント。root 要件を recovery-exec から隠蔽する

### `roles/recovery_exec/templates/sudoers-recovery-exec-mute.j2` (新規)
- `recovery-exec ALL = (root) NOPASSWD: /usr/local/bin/homelab-mute`
- quory の `/etc/sudoers.d/recovery-exec-mute` にデプロイ(target ノードではない)

### `roles/recovery_exec/templates/codex-config.toml.j2`
- `[[execpolicy.rules]] command = "homelab-mute-exec" policy = "allow"` 追加

### `roles/recovery_exec/templates/AGENTS.md.j2`
- "Mute operations (homelab-mute-exec)" セクション追加
  - set / clear / status の用法、ターゲット一覧、用途の説明
- Prohibitions の allowed tools リストに `homelab-mute-exec` を追記

### `roles/recovery_exec/tasks/main.yml`
- homelab-mute-exec を `/usr/local/bin/homelab-mute-exec` にデプロイするタスク追加
- sudoers-recovery-exec-mute.j2 を `/etc/sudoers.d/recovery-exec-mute` にデプロイ(visudo validate 付き)

## 設計判断

- **recovery-io.py 変更なし**: 厳格な pattern 一致は「自然言語」の要求に合わない。Codex の言語理解に委ねる
- **homelab-mute-exec ラッパー**: execpolicy は command 名で許可するため `sudo` 直呼びはできない。ラッパーで root 移行を隠蔽
- **sudoers は quory ローカル**: homelab-mute は quory 上のファイルを操作する。target ノード(authy/monnie)の sudoers-recovery-exec-target.j2 には追加しない
- **AGENTS.md 区別**: "mute は人間が指示する一時停止。recovery は障害対応" を明文化してモデルの混同を防ぐ
