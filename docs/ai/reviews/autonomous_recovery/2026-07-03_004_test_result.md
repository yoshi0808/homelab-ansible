## フェーズ 3: 本番デプロイ

```bash
ANSIBLE_LOCAL_TEMP=/tmp/ansible-local \
ANSIBLE_REMOTE_TEMP=/tmp/ansible-remote \
ANSIBLE_SSH_CONTROL_PATH_DIR=/tmp/ansible-cp \
ANSIBLE_SSH_COMMON_ARGS='-F /dev/null' \
ansible-playbook playbooks/recovery_push_setup.yml -l quory
```

結果: FAIL。

失敗箇所:

```text
TASK [recovery_push : Setup sender side per target]
[ERROR]: conflicting action statements: ansible.builtin.file, loop_var
Origin: roles/recovery_push/tasks/sender_setup.yml:66:3
```

該当箇所:

```yaml
- name: Create drop-in directory for {{ svc }} on {{ push_target.name }}
  ansible.builtin.file:
    path: "/etc/systemd/system/{{ svc }}.service.d"
    state: directory
    owner: root
    group: root
    mode: "0755"
  become: true
  delegate_to: "{{ push_target.name }}"
  loop: "{{ push_target.push_services }}"
  loop_var: svc
```

`loop_var` が `loop_control:` 配下ではなく task 直下に置かれているため、
Ansible が action statement として解釈している。
同じ問題が次の `Deploy recovery-trigger drop-in` task にもある。

### 部分デプロイ状態

デプロイは以下の quory 側 task まで実行された。


確認:


`/home/recovery-exec/.ssh/authorized_keys` は確認時点で存在しなかった。
そのため authy / monnie から quory への incoming push 経路は未成立。
