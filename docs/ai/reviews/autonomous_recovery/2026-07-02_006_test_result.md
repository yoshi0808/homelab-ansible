## フェーズ 4: drill

### mute 連動

```bash

  /usr/local/sbin/recovery-probe.py

```

結果: OK。

確認内容:

- `sophos-fw` は muted skip
- FAIL カウントなし
- firing record なし
- notify queue なし
- drill flag は残存し、次の full drill に使用

抜粋:

```text

PROBE sophos-fw: muted (残 8 分) — skip

DRILL_FLAG_AFTER_MUTED=present
```
