## フェーズ 3: homelab-monitoring-* の動作確認

```bash
# 3a. status (初期状態: ACTIVE)
ansible quory -b -m ansible.builtin.shell \
  -a 'sudo -H -u recovery-exec homelab-monitoring-status'

# 3b. pause
ansible quory -b -m ansible.builtin.shell \
  -a 'sudo -H -u recovery-exec homelab-monitoring-pause'

# 3c. flag ファイル存在確認
ansible quory -b -m ansible.builtin.shell \
  -a 'ls -l /var/lib/recovery-exec/workspace/monitoring-paused'

# 3d. status (PAUSED)
ansible quory -b -m ansible.builtin.shell \
  -a 'sudo -H -u recovery-exec homelab-monitoring-status'

# 3e. yoshi (recovery-probe ユーザー) が flag を読めること
ansible quory -b -m ansible.builtin.shell \
  -a 'sudo -H -u yoshi stat /var/lib/recovery-exec/workspace/monitoring-paused'

# 3f. resume
ansible quory -b -m ansible.builtin.shell \
  -a 'sudo -H -u recovery-exec homelab-monitoring-resume'

# 3g. status (ACTIVE に戻る)
ansible quory -b -m ansible.builtin.shell \
  -a 'sudo -H -u recovery-exec homelab-monitoring-status'

# 3h. flag ファイル消滅確認
ansible quory -b -m ansible.builtin.shell \
  -a 'ls /var/lib/recovery-exec/workspace/monitoring-paused 2>&1 || echo "absent (expected)"'
```

期待:
- 3a: `ACTIVE`
- 3b: `monitoring paused (all targets)`
- 3c: ファイルが存在する
- 3d: `PAUSED (all targets)`
- 3e: stat 成功(exit 0)
- 3f: `monitoring resumed`
- 3g: `ACTIVE`
- 3h: `absent (expected)`
