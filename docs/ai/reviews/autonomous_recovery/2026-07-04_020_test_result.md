## phase 5: cert_renew.yml pause/resume task check

plan の exact command:

```bash
ansible-playbook playbooks/cert_renew.yml \
  --check \
  -e cert_needs_renewal=true \
  2>&1 | grep -E "Pause|Resume|homelab-monitoring"
```

結果: NG / 到達不可。

grep なしで確認したところ、playbook 先頭の quory-only assert で停止した。

```text
TASK [Ensure this playbook is running on quory] ********************************
fatal: [localhost]: FAILED! => {
    "assertion": "ansible_facts['hostname'] == 'quory'",
    "changed": false,
    "evaluated_to": false,
    "msg": "cert_renew.yml must be run on quory only (current host: ansy). CA private key must never be placed on ansy."
}
```

このため ansy から plan の exact command では pause/resume task まで到達できない。

補足確認として、local staged playbook の task list を確認した。

```bash
ANSIBLE_LOCAL_TEMP=/tmp/ansible-local \
ansible-playbook playbooks/cert_renew.yml --list-tasks
```

該当箇所:

```text
play #5 (monnie): cert_renew - issue and deploy monnie cert
  tasks:
    Pause monitoring before grafana-server restart
    ...
    Resume monitoring after grafana restart
```

また、実装上の task は以下の通り。

