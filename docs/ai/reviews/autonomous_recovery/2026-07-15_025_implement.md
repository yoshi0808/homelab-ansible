## 変更内容

### qm 絶対パス

- dispatchの`vm-status` / `vm-config` sudo argvを次へ変更した。
  - `/usr/sbin/qm status "$p1"`
  - `/usr/sbin/qm config "$p1"`
- sudoersの対応するoperand wildcard rule 2行も`/usr/sbin/qm`へ変更した。
- sudoers pre-deploy NOTEの期待path一覧で、`qm`を`/usr/sbin`側へ移動した。
- 2026-07-15のpve1/pve2 target preflightで確認済みの訂正であることをNOTEへ記録した。

### journal unit allowlist

次の全 operational / canonical 箇所で、journal unitの`pvesr`を`pvescheduler`へ
整合差し替えした。

- dispatchのunit case armと固定journalctl argv
- wrapperのunit allowlist
- sudoersのunit固定rule
- sudoers pre-deploy NOTEの`systemctl list-units --all`例
- 配備用`AGENTS.md`のunit一覧
- `autonomous_recovery_policy.md` §4.6のunit allowlist

他の4 unit（`pvestatd` / `pve-cluster` / `corosync` / `pvedaemon`）はtesterがloadedを
確認済みのため維持した。`pvescheduler`の実在は再テスト対象であり、not-foundの場合は
hubの指示どおり5 unit維持を試みず、4 unitへ縮小する判断を行う。
