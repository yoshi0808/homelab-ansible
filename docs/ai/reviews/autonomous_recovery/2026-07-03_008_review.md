## 指摘

### must-fix: drill unit の copy src が解決できず、playbook が check mode で失敗する

`playbooks/recovery_push_drill_setup.yml:27` が `roles/recovery_push/tasks/drill_setup.yml`
をパス指定で `include_tasks` しているため、`roles/recovery_push/tasks/drill_setup.yml:8` の
`src: "recovery-drill-{{ drill_target.name }}.service"` は role の `files/` ではなく、
task/playbook 側の探索パスで解決される。

実際に check mode で以下のエラーになった。

```text
Could not find or access 'recovery-drill-authy.service'
Searched in:
  /home/yoshi/homelab-ansible/roles/recovery_push/tasks/files/recovery-drill-authy.service
  /home/yoshi/homelab-ansible/roles/recovery_push/tasks/recovery-drill-authy.service
  /home/yoshi/homelab-ansible/playbooks/files/recovery-drill-authy.service
  /home/yoshi/homelab-ansible/playbooks/recovery-drill-authy.service
```

このままだと E-3 drill unit は authy/monnie に配布できない。

修正案:

- `drill_setup.yml` を role として呼ぶ構造に変える、または
- `copy.src` を `{{ playbook_dir }}/../roles/recovery_push/files/recovery-drill-{{ drill_target.name }}.service`
  のような明示パスにする。
