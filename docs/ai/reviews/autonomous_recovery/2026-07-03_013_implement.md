## 変更ファイル

`playbooks/cert_renew.yml` — monnie play 内の deploy_grafana 前後に mute 挿入

```yaml
- name: Mute monnie push trigger before grafana-server restart
  ansible.builtin.command: "homelab-mute set monnie 5 'cert_renew: grafana-server restart'"
  delegate_to: localhost
  when: cert_needs_renewal | default(false) | bool

- name: Run deploy_grafana tasks
  ansible.builtin.import_role:
    name: homelab_cert_renew
    tasks_from: deploy_grafana

- name: Clear monnie push trigger mute after grafana restart
  ansible.builtin.command: homelab-mute clear monnie
  delegate_to: localhost
  when: cert_needs_renewal | default(false) | bool
```

### 設計判断

- `when: cert_needs_renewal` — 証明書更新が不要な場合は grafana-server が再起動されないため mute も不要
- `delegate_to: localhost` — cert_renew.yml は quory から実行する前提。localhost=quory で homelab-mute を実行
- `become: true` は play レベルで設定済み。delegate_to: localhost に引き継がれ sudo で root 実行
- mute 時間 5 分 — grafana-server の起動確認(`wait_for port 3000`)完了まで余裕を持たせた
- clear が実行される前に grafana restart が失敗した場合: mute は 5 分後に自動期限切れ
