## スコープ（2026-07-17 確定）

- **含める基準**: そのノードの"役割を定義するアプリケーション"＋自動化基盤ツール（ansible/Codex/Claude Code）。
- **除外**: OS baseline・素の依存（systemd/libssl/python3-*/udev 等）、素のまま載る汎用 plumbing。
- **例外的に含む plumbing**: その役割の主役になっている物（chrony@quory=時刻基準、rsyslog@monnie=受信、rsyslog@pve=転送）。
- **アプライアンスは対象外**: Sophos / UniFi / CloudKey（GUI 管理・Ansible 非対象）。
- 対象ノード: ansy / monnie / authy / quory（Ubuntu VM）+ pve1 / pve2。

## 管理方式の凡例（更新の追い方＝6系統）

| 記号 | 方式 | 既存の版追跡手段 |
|---|---|---|
| **apt-M** | apt（月次 full-upgrade 対象） | `ubuntu_vm_full_upgrade` + important パターン → REVIEW |
| **apt-PVE** | apt（Proxmox 専用 policy） | `proxmox_patch_policy`（別枠） |
| **rel** | 非apt / 上流 Release 突合 | `nonapt_per_node` registry（buildinfo↔GitHub） |
| **npm-A** | npm・自動更新 | `codex_update_check`（週次・Semaphore） |
| **npm-X** | npm・**未管理（空白）** | ─（追跡手段なし＝ギャップ） |
| **prov** | 上流 git からの提供コンテンツ | ─（ファイル provisioning・特殊） |
