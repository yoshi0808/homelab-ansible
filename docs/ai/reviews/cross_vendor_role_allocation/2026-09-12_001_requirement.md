# Implementer / Reviewerのベンダー分離実験

状態: 要件確定。2026-09-12のYoshinobuとの対話を反映。

## 1. 問題定義

Codex Coordinatorのトークン削減を狙ってLunaへ調査や実装の一部だけを委ねても、Coordinatorが調査結果を再読し、設計・実装・差し戻しを引き取るため、月次ストレージ点検案件では3回のトークン枯渇を避けられなかった。一方、Implementerと差分Reviewerを同じClaude Codeへ置く案は、実装の主要な牽制を同一ベンダーへ閉じる。

## 2. ゴール

実装工程全体をClaude Code Implementerへ移し、差分レビューをfreshなCodex Reviewerへ分離する実験配分を導入する。Coordinatorは要求・判断・統合へ集中し、実装ファイルを自ら編集しない運用を検証する。

## 3. 非ゴール

恒久採用、モデル性能の一般的な優劣判定、agmsg本体の変更、Codex/Claude Codeのsandbox・承認設定変更、過去案件のRole表記書換えは行わない。文書だけの軽微変更や緊急時まで機械的に委任する規則にはしない。

## 4. ユーザーストーリー

Yoshinobuは、実装をClaude Codeへ任せてCodexの週間トークン消費を抑えつつ、異なるベンダーのCodex Reviewerによる牽制を維持できる。

## 5. 要件

### P0 / Must

- 非自明な実装案件では、Claude Code Implementerが調査・実装・自己検証・差し戻し対応を一貫して担う。
- 実装差分Reviewerは実装履歴を継承しないfreshなCodex native subagentとし、Implementerと別ベンダーにする。
- TesterもReviewerとは別のfreshなCodex native subagentとし、AuditorはClaude Codeで従来どおり案件クローズ時に1回だけ起動する。
- 計画査読はClaude Code Reviewerが担い、Implementerとは別identityにする。差分ReviewerとはCLIもcontextも共有しない。
- Role割当、model/effort、agmsg経路、ローカルlauncherの構成を同時に更新する。

### P1 / Should

- 次の非自明な実装案件3件で、Coordinatorの実装ファイル編集有無、会話リセット回数、ユーザーが観測できる開始・終了時のトークン残量、レビュー差し戻し回数を案件記録へ残す。
- 3件後に継続・修正・撤回をYoshinobuと判断する。途中でも品質低下または運用不能が観測されたら見直す。

## 6. 成功指標・受入条件

- AC1: Given非自明な実装案件、When実装を開始、ThenClaude Code Implementerが実装工程全体を担当し、Codex Coordinatorは実装ファイルを編集しない。
- AC2: Given実装差分、Whenレビューを開始、Then実装履歴を継承しないCodex Reviewerが検査し、ImplementerとReviewerが別ベンダーである。
- AC3: Given計画査読・差分レビュー・テスト・監査、When各Roleを起動、Then計画ReviewerとImplementerは別Claude identity、差分ReviewerとTesterは互いに別のfresh Codex context、AuditorはClaude Codeとして起動される。
- AC4: Givenローカルlauncherをreset起動、When常駐Roleを確認、ThenClaude CodeのImplementer・計画Reviewer・Auditorが起動し、差分ReviewerとTesterは案件ごとのCodex native subagentとしてのみ起動する。
- AC5: Given変更後、When文書整合検査と独立規範レビューを行う、Then旧配分を現行として述べる記述が残らず、検査はrc0、レビューはblockingなしとなる。
- AC6: Given実験対象3件、When各案件をcloseout、Then評価値が案件記録に残り、3件目の後に配分の継続判断が行える。

## 7. オープンクエスチョン

なし。3件後の継続判断は観測結果に基づいて行う。

## 8. タイムライン考慮

正本変更は次回案件のRole起動前に反映する。gitignoredの`new-session.sh`はrepo変更と別にローカルで更新し、反映には`./new-session.sh --reset`が必要。
