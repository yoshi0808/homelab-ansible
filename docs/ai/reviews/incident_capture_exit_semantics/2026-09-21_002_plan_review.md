# incident-capture exit semantics — 計画査読

日付: 2026-09-21 (JST)
対象: `2026-09-21_001_requirement.md`、現行の collector と service unit

## Summary

P0の方向は、単独バンドルとjournalを維持しながら相関不一致だけの周期をunitの成功に変え、混在時にはexit 2を残すもので、観測された症状を閉じうる。ただし既存Policyとの競合と、成功コードの選択に残る穴を解消するまで実装へ進めない。
