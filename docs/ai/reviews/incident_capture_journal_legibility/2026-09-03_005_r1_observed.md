## 充足の内訳

| 見たもの | 結果 |
|---|---|
| **`level="warning"` で引いて出るか** — Grafanaの既定フィルタと同じ条件で拾えるかがR1の問いそのもの | **出た。** `<4>` prefix が severity として消費されている |
| **失敗行の隣に並ぶか** | **同一秒に並んでいる。** 「失敗した」しか読めなかった場所に理由が出た |
| **`<4>` が本文に残っていないか**(外していれば行頭にそのまま見える) | **残っていない** |
| **件数と各 `collection_errors` の `what` が読めるか**(AC2) | 2件、両方の理由が読める |
| **untrusted な値が落ちているか**(IC-016) | play名・ホスト名とも omitted |

**Coordinatorが事実として収集したものであり、Testerによる受入判定ではない。** 単一の read-only クエリで曖昧さが無いため独立実行を求めなかった(Yoshinobu了承、2026-09-03)。
