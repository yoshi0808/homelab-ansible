# ubuntu_vm_full_upgrade 通知へのバージョン差分表示（requirement）

- 日付: 2026-07-12
- 起案: claude（要件定義・ハブ役）
- 発端: Phase B（ansy実適用）合格後のYoshinobuフィードバック

## 背景

Phase Bは合格したが、月次dry-run通知がパッケージ名と件数のみのため、
「upgradeで何がどう変わるのか」が人間に見えず、apply判断・事後検証の
重点決めができなかった。

`apt-get -s full-upgrade` の出力には
`Inst <pkg> [<旧version>] (<新version> <source> ...)` の形でバージョンが
最初から含まれているが、現行の `ubuntu-full-upgrade-simulate.sh` は
この行からパッケージ名のみを抽出しており、バージョン情報を構造化せずに
落としている（生ログは `raw_tail` に残るが、人間が見る導線がない）。

## 目的

月次dry-run通知（および対応するレポートJSON）に、パッケージごとの
現行→新バージョンを最小限の形式で表示し、Yoshinobuがapply前に
変更内容を調査・判断できるようにする。

表示イメージ（npm outdated 風。最低限バージョンの差異が分かればよい）:

```text
nodejs        20.19.4 → 20.19.5
tzdata        2025a-0ubuntu0.24.04 → 2025b-0ubuntu0.24.04
libgcrypt20   1.10.3-2 → 1.10.3-3
```

## 対象

- `roles/ubuntu_vm_full_upgrade/files/ubuntu-full-upgrade-simulate.sh`
- `roles/ubuntu_vm_full_upgrade/tasks/`（レポート保存・通知組み立て部分）
- 対象ホスト: 既存どおり ansy / monnie / authy / quory（変更なし）

## 実施項目

1. simulate.sh: 既存の `apt-get -s full-upgrade` 出力（sim_out）から、
   Inst行の name / 旧version / 新version、Remv行の name / version を
   構造化してJSONに含める。**追加のaptコマンド実行はしない**
   （既に取得済みの出力からの抽出のみ）。
2. レポートJSON: 構造化した一覧を保存する。既存フィールドとの後方互換に
   留意し、classify.yml の Status判定・important分類の動作を変えない。
3. 月次dry-run通知: ノードごとの候補一覧を「`<pkg> <旧> → <新>`」形式で
   1行ずつ表示する。remove候補がある場合は「`<pkg> <版> (remove)`」等で
   区別する。Slackで桁ズレしない表示（コードブロック等の等幅表示）を検討する。
4. 表示上限: 候補が多いノード向けに、通知へ表示する行数の上限を
   defaults変数で設定可能にし、超過分は「…他N件（レポートJSON参照）」の
   形に切り詰める。既定値は実装者が妥当な値を選ぶ。
5. applyサマリ通知（現状は「full-upgrade 実施完了。reboot: 実施/不要 +
   Criticals」のみで、何が適用されたか分からない）にも、適用パッケージの
   「`<pkg> <旧> → <新>`」一覧を含める。データは同一実行セッション内で
   直前に走るsimulationの構造化結果を再利用し、追加の収集はしない。
   表示形式・上限は項目3・4と同一（2026-07-12 Yoshinobu追加指摘により
   初回スコープへ昇格）。

## 制約

- shellは収集とJSON整形のみ（判定・分類・期待値比較はAnsible tasks側。core.md §7）
- 既存のStatus判定（UPGRADE_READY / REVIEW_REQUIRED 等）・important分類・
  通知の全体構造（件数行・Status行）は変えない。バージョン表示の追加のみ
- playbookの tester-gate 分類・Semaphoreテンプレート・実行経路は変更しない
- 秘密情報・IPリテラルを書かない（core.md §3 / §17）

## 初回実装で除外する範囲

- changelogや更新理由の取得・表示
- important該当パッケージの強調などの装飾（最小限のバージョン差分表示に留める）
