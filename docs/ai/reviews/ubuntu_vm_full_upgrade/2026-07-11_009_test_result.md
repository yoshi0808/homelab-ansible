  しないが、運用上unpollerも重要扱いするならpattern追加を別途検討できる。

- quory: installed python3 family / ansible / ansible-core / chronyをcover。
  `corosync` / `corosync-qdevice` packageはquoryのdpkg一覧に存在せず、過剰matchは発生しない。
