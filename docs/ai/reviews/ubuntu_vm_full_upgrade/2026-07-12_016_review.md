## 指摘

### suggestion: 通知表示上限の有効範囲を検証する

`ubuntu_vm_full_upgrade_notify_detail_max_lines` は設定可能だが、正の整数であることの検証がない。`0` の場合、`_shown` が空のため `_block` 全体の `{% if _shown | length > 0 %}` により、候補が存在しても「…他N件(レポートJSON参照)」も表示されない。負値では Python/Jinja の負の slice として動き、設定値が意味する上限と異なる。

既定値 `20` の通常経路に影響はないため commit ブロッカーとはしない。将来の設定ミスを早期に検出するため、共通処理前に `ubuntu_vm_full_upgrade_notify_detail_max_lines | int >= 1` を assert することを推奨する。
