## 1. monnie journal の自己ノイズ抑止

- drop pipeline は `loki.source.journal "system"` だけが接続する `loki.process "system_pipeline"` に限定されている。file 5 source はそれぞれ別 pipeline へ接続し、この drop を通らない。
- 各 selector は `job="ubuntu-nodes"`, `host="monnie"`, exact full unit, `level=~"info|debug"` の全条件を含む。
- exact unit は `loki.service`, `alloy.service`, `grafana-server.service`, `prometheus.service`, `promtail.service`。部分一致や `.` wildcard を使っていない。
- `warning` / `error` は selector の level 条件に一致せず通過する。unit 不一致、host 不一致、level 欠落も通過する。
- unit と level は既存 journal relabel の `__journal__systemd_unit -> unit`、priority 4値 mapping を利用し、新しい抽出経路は増えていない。
- `stage.match action="drop"` は Alloy 公式の label selector による drop 構文と一致する。

したがって、monnie journal の観測スタック info/debug のみが対象で、file 経由の ansy/quory/authy、pve/Sophos、UniFi には影響しない。

## 2. 正規化 file の message-only 化

- `strip_normalized_prefix: true` は `pve_nodes`, `sophos_fw`, `ubuntu_nodes` の3 sourceだけ。`unifi`, `network_devices`, monnie journal は本文変換対象外。
- 正規化3 sourceでは既存順序を維持し、最初に level、必要な sourceでは2番目 tokenの hostをラベル化した後、次の regex/outputを実行する。

```alloy
stage.regex {
  expression = "^(?:error|warning|info|debug)\\s+\\S+\\s+\\S+\\s+(?P<message>.*)$"
}

stage.output {
  source = "message"
}
```

- rsyslog receiver の実テンプレート `<level> <hostname> <RFC3339 timestamp> <syslogtag/message>` と整合する。
- 既存 `level` / `host` capture と `stage.labels` は削除・変更されていないため、ラベル契約を維持する。
- Jinja render後も River文字列中に `\\s` / `\\S` が正しく1段の regex escapeとして残る。

### regex不一致時の重要リスク

**本文は空にならず、元の行が維持される。** Alloy `v1.17.1` の公式実装では、regex不一致時は extracted mapへ `message` を追加せず returnする。続く output stageは指定sourceがmapに存在するときだけ `*entry` を置換し、存在しなければログを出して本文を変更しない。

- [Alloy v1.17.1 regex stage公式ソース](https://github.com/grafana/alloy/blob/v1.17.1/internal/component/loki/process/stages/regex.go)
- [Alloy v1.17.1 output stage公式ソース](https://github.com/grafana/alloy/blob/v1.17.1/internal/component/loki/process/stages/output.go)
- [loki.process公式仕様](https://grafana.com/docs/alloy/latest/reference/components/loki/loki.process/)

したがって、正規化契約外の行が混入しても空本文化による情報損失は起きない。
