### file source の message-only 化

APPLY 後 epoch `1784323904288054827` 以降の Loki 実データを確認した。

| source / host | 新規行 | host/level label | 正規化接頭辞が残る行 |

| ubuntu-nodes / authy, quory | 6 | 6/6 | 0 |
| sophos-fw | 0 | 観測対象なし | 観測対象なし |

新規行は `systemd[...] ...`、`sshd-session[...] ...`、`kernel ...` のように message-only で、
先頭の `<level> <host> <RFC3339 timestamp>` は消え、`host` / `level` label は維持された。

runtime config 上にも `sophos_fw_pipeline` の regex + message output が存在する。
