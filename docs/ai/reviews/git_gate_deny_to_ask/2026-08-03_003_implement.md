## 1. 変更したもの

### 設定(2ファイル)

| ファイル | 変更 |
|---|---|
| `~/.claude/settings.json`(git管理外) | `permissions.deny` の2件を `permissions.ask` へ移し、`deny` を空配列にした |
| `<repo>/.claude/settings.json` | 同上に加え、`autoMode.hard_deny` の該当節を削除し、同内容を書き換えて `autoMode.soft_deny` の末尾へ移した。`hard_deny` は `["$defaults"]` のみになった |

`soft_deny` へ移した節に、次の3つを本文として持たせた(設定側にしか書けない/書くべき内容)。

- 2026-08-03にYoshinobuがhard blockからここへ移したこと、および**判断は依然Yoshinobuのもの**であること。
- **agentが自らの判断でcommit/pushを一歩として扱ってはならず、stageした内容と提案するメッセージを先に提示すること。**
- **subagentは確認の有無にかかわらずcommit/pushしない。確認を求めることもしない。** ask を使えるのは対話セッションだけである。
- `git add` / `git diff` / メッセージ起草は確認不要(NOT covered)。
