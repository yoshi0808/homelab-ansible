# Closeout: Role別model / effort既定値の固定

作成: 2026-09-07 / Coordinator

## 結論

Role別の通常model / effortを次の値へ固定した。

| Role | CLI | model | effort |
|---|---|---|---|
| Implementer | Codex | `gpt-5.6-luna` | medium |
| Reviewer | Claude Code | `sonnet` | medium |
| Tester | Claude Code | `sonnet` | medium |
| Auditor | Claude Code | `sonnet` | medium |

Implementerは複雑な案件でhighへ引き上げる。Testerのlowは、実ホスト非到達・期待値と手順が完全固定・起動時の明示指定をすべて満たすローカル検査だけに限定した。Coordinator自身のmodelは固定していない。
