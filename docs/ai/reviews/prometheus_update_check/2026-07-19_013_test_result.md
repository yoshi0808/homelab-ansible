### c. Post-swap health failure and automatic rollback

`swap_started=true`、health status `503` として post-swap health assert を失敗させた。

- rescue/automatic rollback path の発火: PASS
- recovery success predicate は次の全ANDであることを truth-table で確認:
  - service active
  - restored version == original current version
  - health HTTP 200
  - prometheus / promtool が regular file
  - prometheus / promtool が non-symlink
  - prometheus SHA-256 == backup SHA-256
  - promtool SHA-256 == backup SHA-256

all-true のみ succeeded。inactive、version mismatch、health failure、どちらかの symlink、どちらかの SHA mismatch はすべて failed 判定となった。
