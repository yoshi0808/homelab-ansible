## 主要な設計判断（Yoshinobu 採択）

- **メジャーバージョン上昇時のみ更新**。マイナー/パッチ差分は更新も通知もしない。
  メジャー部は正規表現で数値検証してから整数比較（不正値は `collection_failed`）
- **self-update 方式（`npm install -g npm@latest`）を正式採用**。npm は NodeSource の
  nodejs deb にバンドルされ dpkg 管理下だが、apt 経由では npm 単独のメジャー更新が
  不可能（Node 本体更新を伴い除外範囲に抵触）なため。dpkg ドリフトは許容し、
  apt upgrade による巻き戻りは週次実行の再検知で自己修復する。更新実施時の
  Slack 通知にドリフト注意文を自動付加
- 更新コマンドは `failed_when: false` + status 記録方式とし、失敗時も必ず集約・
  Slack `alerts`/`error` 通知・最終 `fail` に到達する（既存 Codex CLI 側も同構造に統一）

## 運用メモ

- ansy/quory とも npm 12.0.0 で稼働中。将来 apt upgrade で nodejs が更新されると
  npm がバンドル版（10.9.8 等）へ巻き戻るが、次回の週次実行が再検知して
  自動で最新メジャーへ戻す（採用済みの自己修復サイクル）

  apt で最新に更新してから再実行する（今回の quory の事例）
