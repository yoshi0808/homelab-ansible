## 追記: quory `promise-retry` 失敗の read-only 裏取り

Claude からの追加依頼（Yoshinobu 承認済み）により、パッケージ変更を行わず ansy / quory
の nodejs deb と実ファイルを比較した。

実行コマンド:

```bash
dpkg-query -W -f='Version=${Version}\n' nodejs
dpkg -L nodejs | grep -E '(^|/)promise-retry(/|$)'
test -d /usr/lib/node_modules/npm/node_modules/promise-retry
apt-cache policy nodejs
```

結果:

| 項目 | ansy | quory |
| --- | --- | --- |
| nodejs installed | `22.23.0-1nodesource1` | `22.22.2-1nodesource1` |
| nodejs candidate | `22.23.1-1nodesource1` | `22.23.1-1nodesource1` |
| `dpkg -L` に promise-retry | 3パスあり | 3パスあり |
| promise-retry 実ディレクトリ | なし | あり |

両 deb のファイルリストには次が含まれていた。

```text
/usr/lib/node_modules/npm/node_modules/promise-retry
/usr/lib/node_modules/npm/node_modules/promise-retry/index.js
/usr/lib/node_modules/npm/node_modules/promise-retry/package.json
```

したがって「quory の npm 10.9.7 同梱 deb が `promise-retry` を packaging し忘れた」
という仮説は、現在の静的状態からは**支持されない**。むしろ quory では失敗後も
`/usr/lib/node_modules/npm/node_modules/promise-retry` が実在する。

ansy は dpkg のファイルリストには同パスが残る一方、npm 12 self-update 後の実ファイル
にはディレクトリがない。これは先に確認した `dpkg -V nodejs` の差分と整合し、npm 12
への self-update が dpkg 管理ツリーを書き換えた結果と考えられる。

quory の debug log では npm reify が既存 npm ツリーを一時名
`.npm-qUIFSsiV` へ退避した直後、元パス
`/usr/lib/node_modules/npm/node_modules/@npmcli/arborist/...` から
`promise-retry` を require して失敗している。静的には依存ディレクトリが存在するため、
パッケージへの恒久的な欠落ではなく、self-update 中の既存ツリー rename と旧 npm
プロセスのモジュール解決が競合する可能性が高い。ただしこれはログと実ファイルからの
**推論**であり、根本原因の確定には追加検証が必要。

quory には nodejs `22.23.1-1nodesource1` へのアップグレード候補がある。今回の依頼は
read-only のため apt 更新は実施していない。Yoshinobu が nodejs を更新した後、npm
同梱版と依存ツリーを再確認し、Phase 1〜2 を再テストする。
