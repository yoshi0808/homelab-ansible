## 2. 実装

### 2.1 defaults / validation

defaultsはDNS-name HTTPS URL、request timeout 5、poll interval 15、overall timeout 300とした。Ansible assertはURL string / scheme / userinfo不在 / IPv4 literal不在、timing integer / 正数、`overall >= request`を検証する。helperはURL parse、userinfo / IPv4・IPv6 literal、正数、budget関係を再検証する。

### 2.2 helper lifecycle

gateはHA復帰wait後・healthcheck前・既存not-check destructive block内にある。

1. helperをtarget nodeの一時pathへmode 0700でcopyする。
2. `ansible.builtin.command.argv`でURL / timingsを渡して実行する。
3. rc=0 stdoutのJSONをparseし、status / attempts / elapsedをassertする。
4. fact / JSON reportへ同じ値を記録する。
5. success / network exhaustion / unexpected failureのすべてでhelperをalways削除する。
6. statusが`UNCONFIRMED`なら専用failし、healthcheckへ進ませない。

copy / command / cleanupはgateとして`changed_when: false`である。unexpected helper errorだけはcommand failureとしてouter rescueへ流れる。

### 2.3 HTTP / credential

HEADの正常responseとHTTPErrorは`REACHABLE`、DNS / TLS / transport / timeoutはdeadlineまでretryする。NoRedirect handlerによりredirect先へ移動せず、redirect response自体をreachableにする。

helper openerはproxy空、HTTP / HTTPS、no-redirectだけであり、netrc / proxy credential / Basic / Digest auth handlerを使わない。header / body / authは指定しない。Ansible `uri`は削除したため`use_netrc`の既定値に依存しない。

### 2.4 deadline / attempts / elapsed

`time.monotonic()`のdeadlineを使用し、request timeout / sleepを毎回remaining budgetへcapする。network exhaustionはrc=0 `UNCONFIRMED`と実HTTP回数 / elapsedのJSON、unexpected errorはsecretを含まないerror typeだけをstderrへ出してrc=2とする。

fake testの既定fast-failは20 attempts / 300.0秒、5秒request-timeoutは15 attempts / 300.0秒、HTTPErrorは1 attempt / `REACHABLE`である。overall 7秒overrideでもfast / timeout双方が1 attempt / 7.0秒で停止した。attemptsは実`open()`呼出し回数と一致する。

### 2.5 failure / check / report

network exhaustion後の専用messageは「HA復帰済みだがSophos経由の外部到達性未確認」、healthcheckへ進まないこと、人間が必要時だけ`ansible-playbook playbooks/recovery_vm_reboot.yml -e target=sophos-fw`を手動実行する案内を含む。recovery action自動呼出しは0である。

既存outer rescue / always JSON / re-raiseを維持する。report fieldsはstatus /実attempts / monotonic elapsed。check modeではgate / healthcheck未実行、`NOT_RUN` / 0 / 0と`PLAN_ONLY`を維持する。
