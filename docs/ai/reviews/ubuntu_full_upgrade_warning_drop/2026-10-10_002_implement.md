# Implement: 月次full-upgradeでauthy / monnieのhealthcheck WARNINGを捨てない

実施日: 2026-10-10

## 変更内容

`roles/ubuntu_vm_full_upgrade/tasks/healthcheck.yml` の warnings 集約を、
criticals と同じく `radius_warnings`、`monitoring_warnings`、既存の
`ubuntu_vm_full_upgrade_generic_health.warnings` の連結へ変更した。各値は
`default([])` で未定義時にも空リストとして扱う。誤っていた「radius /
monitoring は warnings を返さない」というコメントも、3種別を集約して既存の
`main.yml` 通知フローへ渡す説明へ更新した。

`tasks/main.yml` の warning 通知・継続処理と critical の処理は変更していない。
