## 5. owner / mode / root_squash

| path | type | UID | GID | mode |
|---|---|---:|---:|---:|
| cache root | directory | 0 | 0 | 0750 |
| date directory | directory | 0 | 0 | 0750 |
| probe (touch 後) | regular empty file | 0 | 0 | 0644 |
| probe (chmod 後) | regular empty file | 0 | 0 | 0640 |

root で作成した directory/file の owner が UID 0 のままであり、匿名 UID へ変換されていない。
さらに root の `touch` と `chmod` が成功したため、この export/path では root_squash はないと判定した。

`prepare`、後続の seed/publish/prune に必要な root write/metadata 操作を NAS が受け付けるため、
root_squash を理由とする direct repository download fallback は不要。
