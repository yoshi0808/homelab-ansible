## 1. Pre-state

monnie で cloudkey の leaf を system CA bundle に対して検証した。

```text
openssl verify -CAfile /etc/ssl/certs/ca-certificates.crt <cloudkey-leaf>
error 2 at 1 depth lookup: unable to get issuer certificate
verification failed
VERIFY_RC=2
```

depth 1 は `<INTERMEDIATE>`。APPLY 前は issuer である `<ROOT>` が trust store に存在せず、期待どおり failure を再現した。

## 4. TLS verification recovery

monnie と ansy の両方で cloudkey を検証した。

### Leaf against system CAfile

```text
openssl verify -CAfile /etc/ssl/certs/ca-certificates.crt <cloudkey-leaf>
<leaf>: OK
LEAF_VERIFY_RC=0
```

monnie、ansy とも同じ結果だった。

### Live TLS chain

```text
openssl s_client -connect cloudkey.internal:443 \
  -servername cloudkey.internal \
  -verify_return_error \
  -CAfile /etc/ssl/certs/ca-certificates.crt \
  -CApath /etc/ssl/certs
Verification: OK
Verify return code: 0 (ok)
S_CLIENT_RC=0
```

monnie、ansy とも return 0。APPLY 前の depth 1 / error 2 は解消した。
