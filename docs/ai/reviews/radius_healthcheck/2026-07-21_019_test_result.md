### Shell fixtures

exportした一時shell function `df()` でheaderと1 data rowを返し、repositoryのshellをそのまま実行した。

```bash
df() {
  printf 'Filesystem 1-blocks Used Available Capacity Mounted on\n'
  printf 'fixture %s %s %s %s /\n' \
    "$FIX_TOTAL" "$FIX_USED" "$FIX_AVAIL" "$FIX_PCT"
}
export -f df
bash roles/radius_healthcheck/files/radius-healthcheck.sh
```

結果:

- 79 / 80 / 89 / 90%: `collection_ok=true`、JSONはそれぞれ同じ整数を保持。

- `105 / 89 / 10 / 90%`: 同条件で90を保持。
- 不正Use% `80`（`%`なし）: `collection_ok=false`、disk数値は全て0。
- `df() { return 1; }`: 同じ失敗JSON。
