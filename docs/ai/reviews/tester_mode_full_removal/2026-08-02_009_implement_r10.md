## 3. 未検証事項・残存リスク

- **AC5の文字どおりの実行はできていない。** `scripts/git-pre-commit-check.sh`はstaged(`git diff --cached`)を前提とするチェック(gitleaks `--staged`、IPv4 literal検査、vault先頭行検査、staged YAML構文検査、`check-doc-consistency.py`)を含むが、`docs/ai/core.md`の「subagentが共通して守ること」により**Implementerは`git add`を行わない**(stage範囲を決めるのはCoordinatorの責務)。そのためstage状態そのものを作れず、スクリプトを文字どおりには実行していない。代わりに以下を作業ツリー上で個別に近似実行し、いずれも異常なしを確認した:
  - `git diff -U0`をIPv4 literal検査と同じgrep/awk条件に通し、ヒットなし。
  - `bash scripts/check-tester-gate.sh`は単体で実行し`OK (49 playbooks)`。
  - vault/secretらしきファイルは今回の差分に含まれない。
  - `gitleaks`はバイナリ存在は確認したが、`--staged`前提のため作業ツリー diffへの代替実行(`--pipe`)はrepo全体(15MB)を対象にした挙動になり、本差分と無関係な既存ファイル(`reports/proxmox-backup-verify/*.json`)のfalse positiveのみを検出した。今回の差分自体に秘密情報が含まれないことの直接証拠にはなっていない。
  - `check-doc-consistency.py`は`git show :<path>`でgit indexを読む設計のため、stageしていない現状では実行しても変更前の内容を検査するだけで意味を持たない。実行していない。
  - **stage状態での`scripts/git-pre-commit-check.sh`本体の実行は、stageを担当するCoordinator/Testerへ委ねる。**
- `docs/ai/reviews/agent_definition_dedup/`等、非ゴールで保護された過去のreview記録内には、今回削除したTS-003/TS-004本文への言及や「背景」節への参照が残っている(例: `2026-08-02_005_review.md`, `2026-08-02_006_test_result.md`, `2026-08-02_001_requirement.md`)。これらは`docs/ai/reviews/`配下であり、requirementの非ゴール(「`docs/ai/reviews/`…を書き換えない」)により意図的に未変更。読み手は当該節が現在は存在しないことを踏まえて読む必要がある。
