## R1: `notify.yml` の抑止条件から `tester_mode` を外す

- `[tester_mode] Show notification instead of sending` タスクの `when:` から `tester_mode | default(false) | bool or` を削除。抑止条件は `skip_notifications | default(false) | bool or ansible_check_mode | bool` の2つのみ。タスク名を `[skip_notifications] Show notification instead of sending` に変更(旧名がtester_modeを冠していたため)。debugメッセージの文言も同様に更新。
- `Send Slack notification (best-effort)` の `when:` も同様に `tester_mode` を外し、否定条件を2条件のみへ縮小。
- ファイル冒頭のコメント(R3のcheck_mode追加を説明していた箇所)からも `tester_mode` の文字列を除去し、「3トリガーのうち1つが撤廃され、渡しても無視される」旨に書き換えた(AC1が「29本の移行assert以外は0件」を要求するため、コメント内の言及も残せない)。

## R2: `recovery_probe` の drill機構を削除

`roles/recovery_probe/files/recovery-probe.py`:
- モジュールdocstringの drill 説明行(`- drill: state_dir/drill/<target>...`)を削除。
- `fire_ladder(cfg, target, tconf, failed_probes, drill)` → `fire_ladder(cfg, target, tconf, failed_probes)` へシグネチャ変更。`label = "[drill] " if drill else ""` と `extra` への `tester_mode=true` 付与を削除(`extra = [f"target={target}"]` のみ)。
- `fire_ladder` 内の全 `queue_notify` 呼び出しから `{label}` プレフィックスを除去(4箇所: flapping、pve到達不能、VM不明、ラダー開始)。
- `stopped` 分岐の `if drill: log(...); return`(start をスキップするdrill専用コード)を削除し、常に `pvesh_vm_start` を呼ぶ元の非drillコードパスのみ残した。
- VM reboot分岐の `if drill: queue_notify(..., "drill 完了", ...); return`(drill完了を無条件`status: ok`で送っていた、本requirementの発端となったコード)を削除。
- `drill_requested()` / `clear_drill()` 関数を削除。
- `main()` の `os.makedirs(..., "drill"), exist_ok=True)` を削除。
- probeループ内の `drill = drill_requested(cfg, target)` と `if drill: ok, failed = False, ["drill"]` を削除し、`probe_target()` の結果をそのまま使う。
- `fire_ladder` 呼び出しを `fire_ladder(cfg, target, tconf, failed)` に変更し、呼び出し後の `if drill: clear_drill(cfg, target)` を削除。
- notify-onlyパス(`action != "ladder"`)の `label = "[drill] " if drill else ""` と、通知後の `clear_drill` 呼び出しを削除。

`roles/recovery_probe/tasks/main.yml`:
- `Ensure probe state directories exist` タスクの `loop:` から `/var/lib/homelab-recovery/probe/drill` を削除(残り2エントリ: `probe`、`probe/notify-queue`)。
