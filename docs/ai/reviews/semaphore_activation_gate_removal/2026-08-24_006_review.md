# Code Review: Semaphore schedule activation gate removal（再レビュー3）

Reviewer: Codex / 2026-08-24  
Verdict: **Request Changes**

## Summary

前回 High 1 の修正は成立している。正常なbool 4組は必要十分な結果を返し、`before_active=None`は未存在から`true`ならブロック対象、desiredが`false`なら非対象となる。文字列・数値・dict等の不正型はtruthinessへ通らずすべて保守側へ倒れ、前回の`"false"`迂回は実Ansible評価でも閉じた。Suggestion 1/2の記録訂正も正確である。

ただし、依頼されたrole全体の横断監査について「他に同じ形は無い」という実装記録は成立しない。template側の既存コードが、API由来の`arguments` / `survey_vars`を`value or []`で正規化し、型違いのfalsy値を正当な空配列と同一化する。現物のread正規化式とreconcile filterをAnsibleで連結し、`arguments: false` / `survey_vars: {}`が`unchanged`になることを再現した。このコードはHEADにも存在する既存欠陥であり、本案件のactivation修正が持ち込んだものではないが、今回の監査結論と記録は訂正が必要である。
