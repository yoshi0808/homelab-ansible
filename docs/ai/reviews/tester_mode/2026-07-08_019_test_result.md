### cert_renew_quory.yml

この playbook は quory 上でのみ実行可能なため、quory の checkout から yoshi ユーザーとして実行した。

初回実行:

```bash
ansible quory -b -m ansible.builtin.command -a "chdir=/home/yoshi/homelab-ansible sudo -H -u yoshi env ANSIBLE_LOCAL_TEMP=/tmp/ansible-local ANSIBLE_SSH_CONTROL_PATH_DIR=/tmp/ansible-cp ansible-playbook playbooks/cert_renew_quory.yml --check"
```

結果: NG。

原因:

- quory 側 checkout の `playbooks/cert_renew_quory.yml` が古く、旧 `tester_mode` plan-only task が残っていた。
- current workspace の同 playbook にある `check_mode: false` 付き `import_role` 実装が未反映だったため、`prepare_ca` の directory 作成が check-mode simulation になり、後続 copy で `/run/semaphore-ca does not exist` により失敗した。

対応:

```bash
ansible quory -b -m ansible.builtin.copy -a "src=/home/yoshi/homelab-ansible/playbooks/cert_renew_quory.yml dest=/home/yoshi/homelab-ansible/playbooks/cert_renew_quory.yml owner=yoshi group=yoshi mode=0644 backup=yes"
```

- backup: `/home/yoshi/homelab-ansible/playbooks/cert_renew_quory.yml.164955.2026-07-08@18:48:56~`
- quory 側で `# tester-gate: check-mode-native`、`Run prepare_ca tasks`、`check_mode: false`、summary の `semaphore deploy/restart skipped` 分岐が存在することを確認。

再実行コマンド:

```bash
ansible quory -b -m ansible.builtin.command -a "chdir=/home/yoshi/homelab-ansible sudo -H -u yoshi env ANSIBLE_LOCAL_TEMP=/tmp/ansible-local ANSIBLE_SSH_CONTROL_PATH_DIR=/tmp/ansible-cp ansible-playbook playbooks/cert_renew_quory.yml --check"
```

結果: OK。

確認 observation:
