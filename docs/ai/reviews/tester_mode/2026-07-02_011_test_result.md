## 実行時の置き換え・追加条件

- 全 playbook 実行に `-e tester_mode=true` を付与した。
- sandbox / SSH 制約回避のため、必要に応じて以下を付与した。
  - `ANSIBLE_LOCAL_TEMP=/tmp/ansible-local`
  - `ANSIBLE_REMOTE_TEMP=/tmp/ansible-remote`
  - `ANSIBLE_SSH_CONTROL_PATH_DIR=/tmp/ansible-cp`
  - `ANSIBLE_SSH_COMMON_ARGS='-F /dev/null'`
- sandbox 内 SSH が `Operation not permitted` で失敗したため、実機接続を伴う read-only / tester-mode 検証は承認済み escalation で再実行した。
- `proxmox_patch_weekly_full` / `proxmox_patch_dryrun` は Claude Code からの承認条件どおりスキップした。
