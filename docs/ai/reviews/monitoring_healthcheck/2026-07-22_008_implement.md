## 実装結果

`roles/monitoring_healthcheck`へ、ルートファイルシステム(`/`)のdisk使用率チェックを追加した。

- `files/monitoring-healthcheck.sh`
  - `LC_ALL=C df -B1 -P /`の2行目からtotal / used / available / Use%を収集する。
  - total / used / availableは非負整数、totalは1以上、Use%は`数字+%`であることを検証する。
  - `used_percent`は`used_bytes / total_bytes`から計算せず、`df`のUse%列から`%`だけを除いて採用する。
  - 収集失敗または想定外形式では`collection_ok: false`、全数値を0にする。
  - JSONへ`disk.collection_ok`、`total_mb`、`used_mb`、`available_mb`、`used_percent`を追加する。
- `tasks/check.yml`
  - disk収集失敗をcriticalへ分類する。
  - `used_percent`の80–89%をwarning、90%以上をcriticalへ排他的に分類する。
  - `monitoring_report.disk`とdebug表示へmemoryと同じ命名規則の5フィールドを追加する。

`tasks/main.yml`、defaults、playbookは変更していない。shellは収集とJSON整形だけを担当し、warning / critical判定とreport構築はAnsible側に維持した。
