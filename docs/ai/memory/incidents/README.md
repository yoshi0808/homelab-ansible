# Incidents

起きた事実そのものを記録する。分類・保存期間・昇格条件は `docs/ai/memory-classification.md` 2節・3節を参照する。ファイル形式(ファイル名規則・記載項目・原因分類タグ)は `skills/incident-recording/SKILL.md` が正本。

**記録は気づいた時点で開始する。** 原因判明・修正完了を待たない。症状だけの`状態: 調査中`で起票してよく、判明後に同じファイルを完成させる。本番影響が出ずに工程内で解決したもの(`種別: 未遂`)も対象。詳細は `skills/incident-recording/SKILL.md`。

既存Claude Memoryの一括棚卸しは行わない(遅延移行のみ)。
