# 月次Knowledge振り返りの測定記録

**このファイルは過去の測定値だけを持つ。** 判断・規範・現在地は書かない。

置く理由は1つで、**後から計算し直せないから**である。各指標はその時点のファイル群から出る値であり、翌月に同じコマンドを流しても返るのは翌月の値である。gitを掘れば復元できるが、それは毎月やる作業ではない。

**対応の有効性は、この系列でしか判定できない。** 「9行が5行になった」と言えるのは、9が残っている場合だけである。

書き方の規律は2つ。

1. **測り方をコマンドで書く。** 翌月に別のやり方で数えると系列が比較できなくなる。機械で数えられないものは「手分類」と明示する。
2. **判断はここに書かず、行き先を指す。** やると決めたことは `docs/ai/status.md`、やらないと決めたことは `decisions/rejected-proposals.md`、原因の断定は `decisions/` の個別ファイルが持つ。
